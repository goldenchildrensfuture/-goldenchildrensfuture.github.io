روضة الأصابع الذهبية - موقع ثابت جاهز لـ GitHub Pages

الملف الرئيسي: index.html

طريقة النشر:
1) أنشئ Repository جديداً على GitHub.
2) ارفع index.html.
3) من Settings > Pages اختر Deploy from a branch.
4) اختر الفرع main والمجلد /root ثم Save.
5) بعد دقائق سيظهر رابط الموقع.

ملاحظة:
التصميم يستخدم Google Fonts عبر الإنترنت. إذا أردت العمل دون اتصال، يمكن إضافة ملفات الخطوط محلياً لاحقاً.
